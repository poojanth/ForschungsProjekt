# KiCad PCB Design for an Implantable Optical Sensor System

## Overview

This project focused on the design and optimization of a printed circuit board (PCB) for an implantable optical sensor system intended for biomedical research. The system concept is based on fluorescence detection for monitoring possible glioblastoma recurrence after tumor resection.

The implant concept consists of two main parts:

* **Sensor Unit** - responsible for fluorescence excitation and detection.
* **Control Unit** - responsible for power management, signal handling, and system control.

The aim of the project was to improve the electrical design, component selection, PCB layout, compactness, and feasibility of the optical implant system.

---

## Key Design Considerations

* Fluorescence excitation using UV/blue LEDs
* Fluorescence detection using photodiodes
* Compact PCB layout for implantable use
* Power-efficient component selection
* Separate power and ground planes for improved signal integrity
* MRI compatibility and biocompatibility considerations
* Sensor and control-unit separation for better placement flexibility
